# householdplanner-bot

The public page about Household Planner's research agent, `householdplanner-bot`, served by GitHub Pages at
https://theavikumar.github.io/householdplanner-bot/. Websites see that address in the agent's User-Agent.

The agent reads public fund fact sheets, one page at a time, obeys robots.txt and never logs in. To keep it out of
a site, add `User-agent: householdplanner-bot` and `Disallow: /` to its robots.txt. To reach its owner, open an
issue here.
